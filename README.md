## 👋 ¿Quiénes somos?

**Xoma Studio** es una empresa salvadoreña que desarrolla software para restaurantes y ofrece soluciones de tecnología para negocios: sistema punto de venta **Xoma POS**, instalación de redes y cableado estructurado, venta de equipos (tablets, UPS y más) y soporte técnico en sitio.

---

## 🍽️ Xoma POS — Punto de venta para restaurantes

Sistema punto de venta rápido y fácil de usar, que funciona **localmente en el negocio del cliente**, sin depender del internet para vender.
