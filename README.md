### 🍽️ Xoma POS

Sistema punto de venta pensado para restaurantes: rápido, fácil de usar y que funciona **localmente en el negocio del cliente**.

- 🧾 Toma de pedidos y gestión de mesas
- 👥 Gestión de clientes
- 📊 Informes, cierres Z y reportes descargables
- 🖨️ Impresión de tickets y comandas con identidad propia

### 🔌 Soluciones de tecnología

- 🌐 Instalación de puntos de red y cableado estructurado
- 💻 Venta de equipos: tablets, UPS y más
- 🛠️ Soporte técnico en sitio
